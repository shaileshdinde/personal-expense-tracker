Expense Tracker API

A REST API for expenses, categories, loans given to others, and reports. All endpoints return JSON in the same envelope and use JWT bearer tokens for authentication.

Base URL

This is the folder that contains index.php / .htaccess on your server (e.g. your API's public/ directory). Every example on this page updates automatically as you change it — try it.

Authentication

Every endpoint except register, login, forgot-password and reset-password requires a bearer token, obtained from POST /api/login:

Authorization: Bearer <token>

Token lifetime depends on the device field sent at login: web → 1 hour, mobile → 30 days. Calling POST /api/logout revokes the current token immediately, even though JWTs are otherwise stateless.
